ScamSense Photo Index Manager

This private tool adds a public image and its source webpage to the ScamSense search index. Only add images and pages that are publicly accessible and that you have permission to index.

Build the public image index

Find openly licensed images on Wikimedia Commons and add them to ScamSense automatically. This gives Photo Search real indexed images to compare against; it does not search the whole internet.

The image itself is processed in this browser. ScamSense stores its perceptual hash and the public image/page links, not the uploaded file. The automatic indexer only adds public Wikimedia Commons images with a recognised free licence.
